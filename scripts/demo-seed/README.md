# Demo data (local only)

`seed_demo_data.py` wipes the local `learning` database and fills it with a complete demo: 2 schools, 8 classes,
1 system admin, 2 school managers, 8 teachers, 40 students and 6 parents, with a full timetable, teacher tests
(past ones graded, upcoming ones scheduled), practice history and skill levels, a gradebook, homework and
submissions, three weeks of attendance, messages and replies, notifications, XP/streaks/badges, daily challenges,
duels, flashcards, a class forum, lesson content, a question bank and an audit log. Dates are relative to the day
it runs, so "upcoming" stays upcoming.

## Run

1. Start the backend once (`backend-dev`), so Flyway applies every migration, then stop it.
2. `python scripts/demo-seed/seed_demo_data.py --yes`
3. Start the backend again (its caches would otherwise still hold the old data) and the frontend.

It refuses any host other than `localhost`, reads `DB_PASSWORD` from `backend/.env`, and keeps
`flyway_schema_history` and the past exams. Back up first if the database holds anything you want
(`scripts/backup-db.ps1`). `--sql-only FILE` writes the SQL without touching a database.
